01 / Get started

打开 App，扫码继续。

先从局域网开始。完成首次设置后，每天只需启动网关，打开手机上的会话。

  1. 1

    下载对应系统的 App

    Windows 可选安装包或免安装 ZIP；Apple Silicon Mac 解压后打开 App。

  2. 2

    启动电脑上的网关

    保持原 Codex App 打开，开启局域网访问，保存配置后点击“启动网关”。

  3. 3

    展开地址下的“扫码登录”

    手机连接可达网络，用相机扫码后在浏览器打开，自动完成登录。

  4. 4

    选择聊天，继续交互

    读取最近回复、补充要求或回应授权；执行仍交给原来的电脑或服务器。

短期、一次性登录。二维码 5 分钟内有效，仅可使用一次；收起或刷新会撤销旧码。普通访问地址仍保留原登录验证。

02 / Your work, on the phone

手机上，也能把事情做完。

iPhone 与 Android 都通过浏览器使用。阅读、发送与确认，围绕你已经在进行的工作展开。

MODEL + SKILL

沿用熟悉的工作方式

选择当前提供商支持的模型与推理强度，随消息附带会话所在主机的 Skill。

SEND / QUEUE / STOP

随时接力

发起新消息、补充当前任务、排队下一条消息，或停止正在运行的任务。

20 → 100 → +100

渐进式读取

先显示最近 20 条，后台补齐到 100 条；上翻接近顶部时再读取更早的 100 条。

中文 / ENGLISH

两端独立切换语言

桌面 App 与手机网页各自记住语言偏好；聊天原文、消息草稿保持原样。

03 / Choose your connection

同一个网关，多种连接方式。

在 App 中添加、命名和启用连接。局域网、临时 HTTPS 与多个固定入口可以并行使用。

手机浏览器阅读与交互
→
同一局域网可达的电脑 IP
→
电脑网关登录与内容同步
→
原 Codex App本机 / SSH 执行
适合：手机与电脑在同一个可互访网络。

启动局域网访问，使用 App 显示的电脑地址。最少配置即可开始，不需要额外域名。

可以同时开启 ✓例如：家里走局域网，出门使用固定 HTTPS。它们连接同一网关，共用登录配置。

扫码只负责登录，网络本身仍需可达。NAS／Docker 提供反向代理入口；原电脑必须保持唤醒，Codex App 和网关需要持续运行。

04 / Know when you are needed

需要你确认时，主动提醒。

为聊天开启提醒后，通过 ntfy 接收待确认通知。点击通知，回到对应会话继续处理。

从待确认，到继续运行

  1. 1
    连接 ntfy 接收端
    手机安装 ntfy 并允许通知，在电脑 App 配置服务与主题，手机订阅相同主题。
  2. 2
    关注需要提醒的聊天
    发送测试通知确认接收后，在手机聊天页开启“提醒”。本机和 SSH 会话可分别关注。
  3. 3
    收到通知，返回会话
    新的待确认请求触发推送。即使网页关闭，网关仍可监听已关注聊天。

iPhone 与 Android 的接收效果取决于通知权限、网络及后台设置。自建 ntfy 的 iPhone 即时推送需要配置 APNs 上游。通知订阅目前按 App 内教程完成。

以后怎样更新 App？

从 beta.5 起，可在“应用更新”中检查新版、阅读说明并点击“更新并重启”。登录、网络、通知和关注聊天配置会保留，原先运行的网关随后恢复；使用临时 HTTPS 时，请重新打开最新地址。更早版本需要先手动安装一次 beta.5 或更新版本。

Mac 提示“已损坏”或开发者无法验证怎么办？

请下载 v0.2.0-beta.5 或更新版本，并先核对 Release 中的 SHA-256。将 App 放入“应用程序”，尝试打开后在“系统设置 → 隐私与安全性”选择“仍要打开”。若仍被拦截，请按 README 首次打开说明 仅放行这个 App。无需关闭系统全局安全保护。当前版本没有 Apple Developer ID 签名和公证。

手机需要登录同一个 OpenAI 账号吗？

不需要。网关拥有独立的登录机制，模型调用沿用原 Codex 会话的提供商与认证。官方登录、API 或自定义提供商是否可用，取决于该会话在电脑端本身能否正常执行。

离开电脑，或关闭电脑后还能用吗？

离开电脑可以，前提是网络入口可达、电脑保持唤醒、原 Codex App 和网关仍在运行。电脑休眠、断网或退出执行会话后，手机无法继续远程操作。

外网访问是不是一键就能配置好？

局域网可以直接启动。临时 HTTPS 需要已有 cloudflared 程序；自有服务器或 NAS 需要先配置 DNS、HTTPS 和转发。App 可导出部署包或生成给 Agent 的配置说明，方便完成首次接入。

可以直接控制所有 Agent App 吗？

当前版本适配 Codex App 的会话与交互协议。其他 Agent App 需要单独适配，不能直接视为已支持。Codex App 自身更新后，内部接口也可能需要重新验证。

二维码可以分享给别人吗？

登录二维码是短期凭据，持有码的人可在有效期内登录，不应公开分享。每个码只能使用一次；收起、刷新或重启网关都会使旧码失效。

长聊天会一次性传到手机吗？

不会。网页先呈现近期内容，再逐步加载历史。工具输出可以按需展开，超长正文也会分段读取；电脑仍保留完整的模型会话上下文。
