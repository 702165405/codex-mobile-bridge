# 本地桌面 2.0.2 修复

本版配套安卓 1.1.1，仅在本地打包安装。

- 修复新版工作台首屏资源同时到达时，网关 TCP 待接收队列过小造成的连接重置。经公网反代会表现为 JS/CSS 返回 502，页面停留在「正在连接工作台」或白屏。待接收队列设为 128，处理线程上限仍为 48。
- 修复桌面「客户端与接入」页仍刷新已禁用 Harness 面板而弹出「此版本仅支持 Codex 和 Claude Code」。页面不再初始化或调用该面板，后端继续限制可用客户端。

验证包含真实 HTTP 并发资源回归和桌面切换页面回归。安装后还需验证公网工作台冷启动及登录；源码测试不能替代实际入口验证。

继续保留原生安卓 Codex 聊天与受控 WebView 工具工作台，登录与本地存储沿用原有加密状态。安卓包和在线更新地址仍为 `https://mac.lqilt.top/android/update.json`。
