首次接入与测试
  1. 手机安装 ntfy

    在 iPhone 或 Android 安装 ntfy，允许系统通知和锁屏显示。

  2. 订阅同一服务与主题

    首次测试可用 https://ntfy.sh。在下方生成随机主题，再把完整主题复制到手机 ntfy 中订阅；主题会自动创建。

  3. 保存，再发送测试通知

    公共匿名主题的 Token 留空。勾选“开启手机通知”，点击底部“保存配置”，然后“发送测试通知”。以手机实际收到为准。

  4. 开启聊天提醒

    启动网关，在手机浏览器刷新并打开已连接的聊天，点击“提醒”直到显示“提醒已开”。随后让 Codex 提出一次选择，锁屏检查是否收到待确认通知。

公共匿名主题没有访问控制，知道主题名的人可读写。请使用随机长名称，首测保留“显示聊天标题”为关闭；正式使用可选择受保护主题。

聊天提醒的测试提示词

请用提问工具让我选择“继续测试”或“结束测试”，等待我的回答，不执行任何命令或文件操作。

测试通知只检查手机接收；聊天提醒还需要电脑、网关、原 Codex App 及相关 SSH 连接在线。

收不到通知或打不开聊天？
  • 先核对手机与电脑的服务地址、主题完全一致；服务拒绝访问时，检查 Token 和主题权限，匿名首测可换一个随机主题。
  • 服务已接受但手机没提示：检查 ntfy 订阅连接、系统通知权限和专注模式。Android 可开启即时投递并允许后台运行；自建服务的 iPhone 即时通知需要配置 APNs 上游。
  • 通知能收到但聊天打不开：保持网关在线。局域网链接需要手机在同一网络；外网访问需要手机可达的 HTTPS 入口。

ntfy 推送

iPhone 和 Android 安装 ntfy 并订阅同一主题，再在手机聊天中开启“待确认提醒”。

默认只推送待处理数量。临时域名变化后，旧通知的链接可能失效。自建 ntfy 的 iPhone 即时通知需要配置 APNs 上游。

已关注聊天

关注开关在手机聊天页面。开启后，关闭网页仍继续监听；取消关注即可停止该聊天提醒。
